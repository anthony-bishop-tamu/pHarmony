Requires python>=3.9
As well as the following packages 
    "numpy>=1.24.0",
    "pandas>=2.0 ",
    "torch>=2.0",
    "matplotlib>=3.2",
    "scipy>=1.10",

Installation (in three easy steps)

Create a conda environment with the following command

> conda create --name PeakMatcher python3=3.9

Activate the Conda environment

> conda activate PeakMatcher

install PeakMatcher with the following command

> pip install git+ssh://git@github.com/anthony-bishop-tamu/PeakMatcher.git

or if you don't have ssh keys with an associated github account

> pip install git+https://github.com/anthony-bishop-tamu/PeakMatcher.git

Test successful installation by typing

> PeakMatcher

You should see a bunch of information about how to use the program outputed
